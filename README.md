# STM32Hal_RadioLib_Interface_Library

A simple library for interfacing the **SX1280 LoRa transceiver** with an **STM32 microcontroller** using the STM32 HAL.

The library uses [RadioLib](https://github.com/jgromes/RadioLib) for LoRa radio communication.

## Features

- Interface between STM32 HAL and RadioLib.
- Support for the SX1280 LoRa transceiver.
- Designed for STM32 microcontrollers.
- Simplifies the integration of RadioLib into STM32 projects.

## Dependencies

This library is based on:

- [RadioLib](https://github.com/jgromes/RadioLib) – Arduino-compatible library for wireless communication modules.

## Usage

For an example of how to use this library in a practical application, have a look at my LoRa wireless module project:

**[LoRa Wireless Module V1 – Project Documentation](https://www.transistorundko.com/electronics_sw/c++/lora_wireless_module_v1/index.html)**

The project describes the implementation and usage of the library.

## Hardware

- STM32 microcontroller
- SX1280 LoRa transceiver
